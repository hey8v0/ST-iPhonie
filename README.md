# ST-iPhonie 📱

给酒馆装一部小手机。

角色会用手机给你发消息、打电话、发朋友圈；正文里的台词能用角色自己的声音念出来；剧情里的画面能自动画成图；还能把正文当成视觉小说来看，累了就去玩一会儿游戏。

> 现在是测试版（0.8.65），欢迎试用和反馈。最近改了什么见下面的「最近更新」，完整记录在 **[更新日志](更新日志.md)**。

## 它能做什么

### 手机里的生活

- 💬 **聊天**：QQ 风格的私聊和群聊，红包、转账、拍一拍、语音消息、分享歌曲都有；一个人可以开好几个聊天窗口。钱包和商城里能买气泡、挂件、背景和礼物送给角色，角色也会送你东西。聊完可以「带进剧情」，下一段正文就会接上。
- 📞 **电话**：角色会用自己的声音给你打电话，屏幕上有字幕；你打字回话。没接到会变成未接来电，还会留语音留言。
- 🌸 **朋友圈**和 🗨️ **论坛**：角色会发动态、互相点赞评论；论坛有热搜，角色和路人网友会发帖、盖楼。你发的内容也会有人回。
- 🔍 **查手机**：拿起角色的手机，看 TA 的聊天、相册、备忘录、搜索记录和购物车。
- 🧠 **记忆和知情范围**：更早的聊天会自动整理成摘要，回消息时还能想起相关的原话。手机上的人只知道自己在场或被告诉过的事，不会全知。
- 📨 **正文联动手机**：正文里有人发消息、发照片、转账、打电话、发朋友圈，手机上真的会收到。

### 让正文活起来

- 🔊 **正文配音**：台词旁边出现小声波，点一下就用角色自己的声音念。支持 Fish Audio、MiniMax、ElevenLabs、小米 MiMo、火山引擎豆包语音，也能接自己跑的语音服务（GPT-SoVITS 等）。还有台词小窗、逐句「听取」和连叙述一起读的「整篇朗读」。
- 🎨 **正文配图**：用 NovelAI、GPT 生图或自己的 ComfyUI 按剧情挑画面出图，同一个角色每张图都长得一样；可以用 Vibe 统一画风。
- 🎬 **视觉小说**：把正文放成 galgame 来看——背景、立绘、对话框、配音一句一句来，立绘会按情绪换表情、做动作，叙述里的雨雪、闪电、回忆都有演出。
- 🎵 **背景音乐和音效**：剧情会按场景放背景音乐，正文里的音效演到那里才响（音源由你自己添加）。

### 自己玩

- ✨ **助手**：独立的聊天 App，可以聊剧情、帮你画图、做小工具。
- 🖼️ **绘图**和 🖌️ **画画**：绘图用 AI 出图；画画是手指和数位板都能用的画板，有图层、笔刷、选区，能导入 Procreate 和 Photoshop 的笔刷。
- 🎧 **音乐**：本机的歌和你自己添加的音源，歌词跟着唱。
- 🎮 **小游戏**：2048、贪吃蛇、俄罗斯方块、五子棋、扫雷等，离线就能玩。
- 🧱 **大游戏《方块世界》**：自己从零做的方块世界——无限的地形、洞穴和矿石、昼夜，挖、放、合成、熔炉，动物和夜里的怪物，生存和创造两种模式；有正版《我的世界》Java 版可以导入它自己的材质。键鼠、手柄、触屏都能玩，手机自动横屏。
- 🗺️ **大游戏《南极结界》**：像素风的探索与种田游戏，在鲸湾郊外的小农场安家，养一只宠物，去海边赶潮、观察生物、记满见闻录（暂缓更新）。

### 其他

相册、备忘录、语音收藏、三套主题（日夜各一版）、动态壁纸、头像挂件；「日志」能看到每次请求模型的内容，「自检」帮你查哪里没配好；聊天记录和设置可以备份，也能存进你自己的酒馆、换设备继续用。

电脑上，小手机是浮在正文旁边的窗口，按住上方的横条可以拖到任何地方；在手机上打开就是全屏。

## 安装

在酒馆里打开「扩展 → 安装扩展」，粘贴：

```
https://github.com/hey8v0/ST-iPhonie
```

装好以后，点屏幕边上的悬浮球、输入框左边魔法棒菜单里的「小手机」，或者在扩展设置里点「ST-iPhonie → 打开小手机」。

需要：SillyTavern **1.13.2 或更新**。用 localhost、HTTPS 或局域网地址（http://192.168.…）打开都行，不用另外装任何服务。也可以装在 TauriTavern（App 版酒馆，对应酒馆 1.18）里。

更新：在扩展管理里点更新，再刷新页面。角色、预设、聊天记录都会保留。

## 第一次用，按这个顺序来

1. **只想聊天、刷朋友圈、接电话（不要声音）**：什么都不用填，直接用酒馆现在连着的模型。打开「聊天」→ 右上角「＋」→ 选一个角色就能聊。
2. **想听到声音**：在「引擎」里填一家语音服务的密钥，再到「角色」里给角色选一个音色。回酒馆正常聊天，台词旁边出现声波，点一下就会念。
3. **想要配图**：在「引擎 → NovelAI」里填 `pst-` 开头的密钥（直连容易断的话可以填自己的中转地址），再到「设置」里打开「正文出图」。想用 GPT 生图或 ComfyUI，就在「引擎」里填好它们，再到「绘图」顶上切过去。
4. **想看视觉小说**：在任意一层楼的小手机工具菜单里点「从这层看视觉小说」。立绘可以在「视觉小说」App 里画或上传。

NovelAI 和 GPT 生图都可以保存多组连接（右上角「⋯ → 连接」）。ComfyUI 的方案、LoRA、模型和参数都在绘画 App 里管理，能导入 API 格式 JSON 或酒馆工作流。

## 最近更新

- **0.8.65** 《方块世界》的光影重做（参照光影包的效果，代码是我们自己写的）。中、高两档改成先把整个画面画成高动态范围，最后统一调色：太阳、火把、亮的天空会晕开（泛光），色调和颜色重新调过，白天的明暗更分明，夜里暗处不再发蓝发亮；云有了厚度，迎着太阳的边缘发亮，地上能看到云影；方块按自己的贴图显出凹凸；树叶和草迎着太阳会透光；水能看到底下，越深越蓝，岸边有泡沫，高档还会倒映岸上的山和树；下雨时露天的地面变暗、发亮，低洼处有水洼，雨丝也淡一些；手里拿着火把（或别的发光的东西）时身边会亮；山洞里的雾是暗的（以前是天空的颜色，一片发白），曝光也稍微提高；高档再加角落的阴影和穿过缝隙的光束；锯齿边会柔化。手机默认的「低」档也换了新的光照和色调。另外修了：高档的光束以前在手里拿着东西时会穿过山和树；平地上的动物和第三人称的自己有时显得很暗（那一层没有方块时，光照被算成了全黑）。
- **0.8.64** 《方块世界》的树和森林照原版重做。树的长法照原版的规则：橡木、白桦这些树顶上的原木现在被树叶盖住（以前树冠低了一格，树干从顶上露出来），各种树的高度也照原版；新加了大橡树（树干上伸出枝杈，挂着几团树叶）、高白桦、松树（长长的光树干，顶上一个尖尖的小树冠）、巨型云杉和巨型松树（2×2 的粗树干，二三十格高，周围的地变成灰化土）、巨型丛林木（2×2 的树干，往外伸出侧枝）；金合欢的分叉、深色橡木挂在树冠下的原木也照原版。丛林木和沼泽橡树挂满藤蔓，丛林木上长可可果。新的生物群系：原始松木针叶林和原始云杉针叶林（巨型云杉、灰化土和砂土、苔石堆、大型蕨）、原始桦木森林（高白桦）、繁花森林（满地的花，还有丁香、玫瑰丛、牡丹）、向日葵平原（向日葵都朝东）；每个生物群系里各种树的比例照原版。新方块：藤蔓（能爬，会慢慢往下长，扒着的方块没了就掉，只有剪刀能收）、可可果（种在丛林木侧面，慢慢长熟，熟了掉三颗可可豆）、高草丛、大型蕨、向日葵、丁香、玫瑰丛、牡丹（两格高，拆掉一半整棵都没了）。骨粉撒在草和蕨上会长成两格高的，撒在两格高的花上会多给一朵，撒在可可果上能催熟；四棵云杉树苗或丛林木树苗摆成 2×2 会长成巨型树，橡树苗有一成长成大橡树。可可豆加小麦能做曲奇；剪刀能收草、蕨和枯萎的灌木。另外修了：站在地上贴着梯子往前走爬不上去（以前要先跳一下）。
- **0.8.63** 音乐小窗放纯音乐（没有歌词，或者只有「纯音乐，请欣赏」和作曲署名）时简洁了：小药丸里只有转动的唱片和声波，展开也只有歌名、歌手和按钮，不再写歌名和「这首歌没有歌词」。《方块世界》有了光影、远景和预生成。设置里的「光影」分关、低、中、高四档：低是更真实的光照（太阳、天空和火把的光分开算，明暗按真实的亮度混合）、会起伏反光的水面（远看映着天空，太阳底下有一道亮光）、跟着太阳变色的天空和雾；中再加上影子（方块、树、生物、村民都会在地上投下影子，随太阳慢慢移动）和有体积的云；高的影子边缘更柔和，还有从树缝和山边漏下来的光束，画面四角稍暗。太阳斜着走过天空，日出日落时天边是橙红的，夜里星星会闪，火把照着的地方是暖黄色，下雨时远处更朦胧，在水下是一片青绿。「远景」把视野外面的地形用大一点的方块画出来，能看到 24、48 或 96 个区块（最远约 1500 格）外的山、海、雪顶和森林，越远越粗，几乎不占性能。暂停菜单里的「预生成地形」可以先把周围 8、16 或 32 个区块的地形生成好、存起来，之后走过去直接读取，手机上走得更顺；可以一边玩一边生成，随时停。存档的方块改成连续压缩，同样的世界占的地方只有原来的六分之一左右（旧存档照常能读）。画面卡的时候会自动把清晰度降一点，不卡了再升回来。手机默认光影「低」、远景 24 区块，电脑默认「中」、48 区块。

## 要花钱吗

插件本身免费，花的是你自己那些服务的额度：

- **语音**：只在你点播放、试听、接电话的时候生成，生成过的会存下来，再听不再扣。
- **配图**：NovelAI Opus 订阅在免费档里画图不扣 Anlas；会扣的时候插件会先问你。
- **文字**（聊天回复、朋友圈、电话里说的话）：每次都会调用一次模型，和你平时在酒馆聊天一样计费。不想占用正文用的模型，可以在「引擎 → 文字模型」里换成另一个（OpenAI 格式的接口都行）。

## 密钥和聊天记录安全吗

- **密钥**：只存在你自己的浏览器里。插件直接连接语音和画图服务，不经过任何别人的服务器。
- **聊天记录与记忆、助手会话、朋友圈、相册**：默认存在浏览器里。在「设置 → 保存到酒馆」打开后，会存进你自己的酒馆，换设备、清浏览器都不会丢。
- **中转**：NovelAI 和 Fish Audio 都可以填中转地址（公益站、自己搭的反代）。
- **备份文件**：默认不带密钥；想带的话可以设一个密码，加密后再放进去。

## 遇到问题

- **台词旁边没有声波**：看看「设置 → 配音 → 正文语音」是不是开着。如果是台词格式写歪了，那条回复下面会提示哪一句不对。
- **点声波没声音、报错**：页面底部会弹出红色提示，写着服务返回的原因。ElevenLabs 免费账户开着 VPN 很容易被停用。
- **密钥在官网能用，插件里却提示 401**：多半是复制时带进了看不见的字符。回官网重新复制一次，粘贴后点「保存密钥」；引擎卡片上会显示已保存密钥的末尾 4 位，可以和官网的对一下。
- **角色只有字幕、没有声音**：还没给这个角色选音色，去「角色」里选一个。
- **电脑上小手机挡住了按钮**：拖开它，或者点横条上的「小」换成小号。
- **标签会不会影响正文**：不会，也不用自己写正则。发给模型时插件自动去掉旧回复的配音标签和出图块，酒馆里的正文、声波和图片照旧。
- **和总结、记忆类插件一起用**：排除标签填 `<tts></tts>` 和 `<img></img>`。
- **还是不知道哪里坏了**：打开「设置 → 自检」，复制报告发给我（报告里没有密钥），或者在 GitHub 上提一个 Issue。
