# ST-iPhonie 📱

给酒馆装一部小手机。

角色会用手机给你发消息、打电话、发朋友圈；正文里的台词能用角色自己的声音念出来；剧情里的画面能自动画成图。

> 现在是测试版（0.8.5），欢迎试用和反馈。

0.8.5 声波下载、收藏菜单按文字宽度收紧，移除右侧空白，保留手机触摸间距。

0.8.4 豆包语音使用独立的黄绿色，并适配日夜主题；情绪与语气标签区域去掉说明段落，只保留实际可用标签，无标签的引擎不显示空区域。

0.8.3 引擎新增火山引擎「豆包语音」，支持合成 2.0/1.0、已有复刻音色、新旧控制台鉴权、缓存与收藏下载。配音预设新增「自由正文」：前面的英文、双语和美化排版保留，只将有效 tts 标签换成声波；原来的译文配对模式保留。

0.8.2 「隐藏正文点击按钮」可移除正文声波、图片操作、音效、音乐和楼层入口，已生成图片保留显示。楼层新增快捷工具栏，可生图、进入视觉小说、整条播放；长按声波可单句下载或收藏，菜单跟随酒馆主题。语音预加载增加内存与解码预热，缓存播放不再等待 Fish 模型目录联网。自定义文字、绘图和语音接口支持酒馆 /proxy/https://… 代理地址。

## 它能做什么

- ✨ **助手**：第二页的独立聊天 App，可以聊剧情、提建议或闲聊；支持新建、切换和删除会话，可选酒馆预设、条目开关和正文上下文，回复里的语音可以试听，HTML 可以预览交互。
- 💬 **手机聊天**：QQ 风格，私聊、拉群、发红包、拍一拍、语音消息都有。还有钱包和商城：红包转账进出零钱，买更好看的气泡、挂件、背景，买礼物（也能自己加）送给角色，角色也会送你礼物。聊完可以把这段聊天「带进剧情」，下一段正文就会接上。
- 📞 **角色给你打电话**：用角色自己的声音说话，屏幕上有字幕。你打字回，和聊天一样可以连说几句，再点气泡让 TA 回话。没接到会变成未接来电，还会留语音留言。
- 🌸 **朋友圈**：角色们会发动态、互相点赞评论，你发动态他们也会来回复。
- 🗨️ **论坛**：公开的论坛，有热搜，角色和路人网友都会发帖、盖楼；你发帖、回帖也会有人回。
- 🧠 **聊天记忆**：更早的聊天自动整理成摘要、阶段总结、长期总览，回消息时还会想起相关的旧原话（可接向量模型）；电话、查手机、朋友圈都记得，也可以带进正文。
- 🔍 **查手机**：拿起角色的手机——锁屏、桌面，点开 TA 和别人的聊天、相册、备忘录、搜索记录、购物车；只写 TA 知道的事，不会全知。
- 🔊 **正文配音**：台词旁边出现一个小声波，点一下就用这个角色的声音念出来。支持 Fish Audio、MiniMax、ElevenLabs、小米 MiMo，可以每个角色用不同的家。
- 🎨 **正文自动配图**：用 NovelAI、GPT 生图或自己的 ComfyUI 按剧情挑画面出图，同一个角色每张图都长得一样；可以用 Vibe 统一画风（能导入官网和智绘姬的 Vibe）。
- 🧸 **其他**：听取（像 Galgame 那样逐句播放）、相册、备忘录、语音收藏、三套主题（日夜各一版）、动态壁纸、聊天气泡和头像挂件……

电脑上，小手机是一个浮在正文旁边的窗口，按住上方的横条可以拖到任何地方，能边看正文边聊天、打电话；在手机上打开就是全屏。

## 安装

在酒馆里打开「扩展 → 安装扩展」，粘贴：

```
https://github.com/hey8v0/ST-iPhonie
```

装好以后，点屏幕边上的悬浮球、输入框左边魔法棒菜单里的「小手机」，或者在扩展设置里点「ST-iPhonie → 打开小手机」。

需要：SillyTavern **1.13.2 或更新**。用 localhost、HTTPS 或局域网地址（http://192.168.…）打开都行。不用另外装任何服务。也可以装在 TauriTavern（App 版酒馆，对应酒馆 1.18）里。

更新：在扩展管理里点更新，再刷新页面。角色、预设、聊天记录都会保留。

## 第一次用，按这个顺序来

1. **只想聊天、刷朋友圈、接电话（不要声音）**：什么都不用填，直接用酒馆现在连着的模型。打开「聊天」→ 右上角「＋」→ 选一个角色就能聊。
2. **想听到声音**：在「引擎」里填一家语音服务的密钥，再到「角色」里给角色选一个音色。回酒馆正常聊天，台词旁边出现声波，点一下就会念。
3. **想要配图**：在「引擎 → NovelAI」里填 `pst-` 开头的密钥（直连容易断的话可以填自己的中转地址），再到「设置」里打开「正文出图」。想用 GPT 生图或 ComfyUI，就在「引擎」里填好它们，再到「绘图」顶上切过去。

NovelAI 和 GPT 生图都可以保存多组连接：右上角「⋯ → 连接」里新建、切换、改名、删除；地址和密钥填完点一下别处就保存了。旧配置会保留为「默认连接」。

ComfyUI 的方案、LoRA、模型和参数都在绘画 App：先选方案，换 LoRA、调参数并试画，满意后保存或另存。点「管理」导入 API 格式 JSON 或酒馆工作流、改名和删除；不用第三方 LoRA 管理器。引擎页只设置地址和连接。详细说明收在小 i，已有方案和旧工作流继续保留。

## 要花钱吗

插件本身免费，花的是你自己那些服务的额度：

- **语音**：只在你点播放、试听、接电话的时候生成，生成过的会存下来，再听不再扣。
- **配图**：NovelAI Opus 订阅在免费档里画图不扣 Anlas；会扣的时候插件会先问你。
- **文字**（聊天回复、朋友圈、电话里说的话）：每次都会调用一次模型，和你平时在酒馆聊天一样计费。不想占用正文用的模型，可以在「引擎 → 文字模型」里换成你自己的另一个（OpenAI 格式的接口都行）。

## 密钥和聊天记录安全吗

- **密钥**：只存在你自己的浏览器里。插件直接连接语音和画图服务，不经过任何别人的服务器。
- **聊天记录与记忆、助手会话与记忆、朋友圈、相册**：默认也存在浏览器里。在「设置 → 保存到酒馆」打开后，会存进你自己的酒馆，换设备、清浏览器都不会丢。
- **中转**：NovelAI 和 Fish Audio 都可以填中转地址（公益站、自己搭的反代）。
- **备份文件**：聊天记录、聊天记忆可以分别选择；助手会话连同各自记忆和已发送附件一起保存，生成图片需同时带上相册。也可以带上 Vibe 和 Vibe 组。向量检索缓存需要时重建。默认不带密钥，想带的话可以设一个密码加密后再放进去。旧备份仍可恢复，不会清空它没有包含的记忆。

## 遇到问题

- **台词旁边没有声波**：看看「设置 → 配音 → 正文语音」是不是开着。如果是台词格式写歪了，那条回复下面会提示哪一句不对。
- **点声波没声音、报错**：页面底部会弹出红色提示，写着服务返回的原因。ElevenLabs 免费账户开着 VPN 很容易被停用。
- **密钥在官网能用，插件里却提示 401**：大多是复制时带进了看不见的字符，0.6.25 起插件会自动去掉；还不行的话，回官网重新复制一次，粘贴后点「保存密钥」。引擎卡片上会显示已保存密钥的末尾 4 位，可以和官网的对一下，看看是不是存的旧密钥。
- **角色只有字幕、没有声音**：还没给这个角色选音色，去「角色」里选一个。
- **电脑上小手机挡住了按钮**：拖开它，或者点横条上的「小」换成小号。
- **标签会不会影响正文**：不会，也不用自己写正则。发给模型时插件自动去掉旧回复的配音标签（只留中文译文）和出图块，酒馆里的正文和声波、图片照旧。
- **和总结、记忆类插件一起用**：排除标签填 `<tts></tts>` 和 `<img></img>`。
- **还是不知道哪里坏了**：打开「设置 → 自检」，复制报告发给我（报告里没有密钥），或者在 GitHub 上提一个 Issue。
