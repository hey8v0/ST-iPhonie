# ST-iPhonie browser-next

这是独立安卓测试版，基线为正式版 `7ed20a6`。同一个小手机安装目录、酒馆账号和浏览器 Profile 会继续使用。安装器核对目标文件后原位更新，遇到未识别的自定义文件时会停下。桌面浏览器入口也可以直接使用网页分享菜单。

## 安装和恢复

1. 在手机浏览器下载本分支的 `ST-iPhonie-Browser-Next.sh` 到下载目录。
2. 在 Termux 执行 `bash ~/storage/downloads/ST-iPhonie-Browser-Next.sh`。第一次允许 Termux 读取下载目录时运行 `termux-setup-storage`。
3. 刷新酒馆并打开小手机浏览器。连接后打开「•••」体验标签页、缩放、键盘和分享。兼容画面可在菜单中选「适应画面」。系统浏览器用 `http://127.0.0.1:6089/vnc.html?autoconnect=1&resize=scale` 仍可打开原 noVNC UI。
4. 恢复时运行 `iphonie-browser restore-release`，再刷新酒馆。装过可选网页服务时，同时重启一次酒馆。

## 网页分享和真实搜索

分享时检查实际网址、已填文字及截图，选好聊天再发送。Firefox 可以按需复制选中文字和截取当前画面。公开网页读取仅获取可访问 HTML 里的标题、简介和正文段落。私人页和视频字幕可手动粘贴经过确认的内容。截图只在主动选择后才会保存，并沿用聊天模型现有的看图能力。

可选的酒馆端组件在 `plugins/iphonie-web/index.mjs`。安装器会先询问是否复制。需要使用时，在确认酒馆的服务端插件配置后设置 `enableServerPlugins: true` 并重启。该选项适用于酒馆内已安装的所有服务端插件。进入小手机「浏览器 → ••• → Char 真实搜索设置」，检查服务状态并保存 Brave Search API 密钥后再启用。Firefox、VNC 和图形服务可全部关闭。模型仅能请求有界的搜索词、从返回结果选择编号，网页卡片的标题和网址由服务端结果提供。

## 真机验证

- 用默认和兼容画面模式分别连接一次，确认竖屏、横屏、键盘弹出后点按位置一致，验证全屏退出和桌面／移动响应式模式切换。
- 在 B 站检查按钮、拖动进度条、音画同步和视频全屏。Firefox 的网页全屏、Firefox 全屏和小手机全屏是独立的。画中画仍由 Firefox 管理。
- Firefox 响应式模式用实际页面视口，设备预设仍由 Firefox 选择。VNC 手势仍转换为鼠标、滚轮或修饰键。中文可通过「粘贴或输入中文」在手机输入法中完成组合，再发送到远端输入框。
- 保持一个网站打开，切换小手机 App、锁屏解锁及切换网络。回来后应能够继续原会话，或显示错误并提供重新连接。安卓回收服务后可重新运行 `iphonie-browser`。
- 给角色发一个网页卡片，重新打开会话检查链接、截图和附言。再关闭 Firefox，开启已配置的 Brave 搜索，在私聊里请角色查一条现实的公开资料，检查卡片链接来源。

开发机测试使用模拟 Firefox、Xvnc 与 noVNC 状态，检查真实回环传输、故障隔离、内容限额和持久化。音频、播放器触控、不同 DPI、真实连接和长期后台运行以安卓机为准。
