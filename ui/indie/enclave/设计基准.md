# 南极结界 · 探索生活原型

## 已确认方向

用户明确授权推翻重做旧《鲸湾小镇》。最终选择：所有场景统一斜俯视，角色可以跑、跳、使用能力并自由探索，不采用横向或混合视角。捏人是确定需求，种田只占生活玩法的一部分。

长期参考为《八方旅人》的精致画面、《星露谷物语》的内容与生活系统、《命运召唤：尔茄的精灵石》的动作、技能、探索与日常交织。不能把一个短原型称为已经达到三款成品的完成度。

已阅读用户提供的本地《精灵石》操作说明，并核对 Lizsoft 的官方 Steam 介绍（https://store.steampowered.com/app/1381770/）。未运行其 EXE，未提取或复制其受保护的美术、音频、角色或故事。参考的是动作与探索的设计关系。

世界设定依据 `Antarctic/南极结界.json` 的八项世界书，以及已有地图的地理结构。鲸湾是背山面海的密集港城，各族混居、石木建筑与阁楼、通用代币、公共生活和近郊探索。跨大区采用真实交通关系，不能把整片大陆压成步行地图。不伤害原则约束居民互动；野外敌对对象为逸散能量，不将居民当掉落材料的怪物。

## 本轮可验收范围

1. 独立捏人：名字、族群、体型、脸型、发型、肤色、发色、瞳色、服装及配色、配饰，外观真正进入场景并保存。
2. 统一斜俯视下的真实高度：自由走跑、起跳、空中落点、平台侧碰撞、落地、跌落恢复。
3. 有时机的近身连击、踏风空中冲刺、回声找隐藏物、潮幕抵挡冲击；野外能量团有预警与恢复期。
4. 一段连贯的内容：鲸湾登记 → 听潮岸点亮三盏风灯 → 获得回声 → 庭院寻找航运记录 → 返回港岸获得潮幕。院落种花、采集、制茶作为可选日常。
5. 键鼠、触屏与标准映射手柄；暂停/后台停止模拟和世界绘制，退出释放资源。分场景加载。
6. 新存档键与旧农园分开；旧存档保留，不静默覆盖。提供导出与导入。全世界地图只列出已制作内容，不把未完成区域伪装成可玩。

## 当前文件

- avatar.js / assets.js：分层原创人物、外观归一化、动作图集、树木、地面与物件。
- world.js / model.js：三处局部场景、实体碰撞、动作模拟、任务、战斗与可选日常。
- renderer.js：斜俯视立体地形、房屋、角色与技能反馈；复用资产、静态实例化、资源回收及慢帧降分辨率。
- main.js / index.html / style.css：捏人、键鼠/触屏/手柄、任务交互、地图与行囊、存档导入导出、暂停与退出。
- 大游戏启动器已切换为新版《南极结界》；旧鲸湾目录和存档保留。
- tests/enclave.test.mjs 覆盖外观、动作与碰撞、跌落恢复、任务奖励、战斗、日常与历法；tests/enclave-browser.cjs 覆盖真实界面输入、保存恢复、导入导出、移动布局、资源回收及启动器诊断。

当前是第一段可玩探索原型。资产仍有程序化重复感，区域密度、角色细节、社交剧情、长期成长和完整世界需要逐轮制作；不能据此宣称已达到目标参考作品的完成度。
房屋立面/屋瓦可复用旧鲸湾原创资产；旧人物、树木和地形需要重做。新项目不继续堆叠在旧农园控制逻辑上。

## 手机约束

单场景渲染、共享纹理、复用几何、实例化静态部件；手机默认像素比 1、阴影 512、稳定 30 帧目标，持续慢帧降低内部渲染尺寸。能力效果使用少量预分配对象，避免每次攻击创建纹理/材质。不依赖运行时大模型生成游戏内容。降速模拟和截图不等同于真机性能。
