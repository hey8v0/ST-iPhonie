# 鲸湾：南极结界的第一个可玩街区

## 设定来源

本次以用户提供的 `E:/NanaGame/Antarctic/南极结界.json` 为设定依据，已阅读本质、地理、社会、历史、地点、经济、历法、医教八个条目。补充核对了 `map/web/data/places.json`、`meta.json` 和 `mv/src/scenes/bay.mjs`。不修改外部目录，不将整份世界书或地图原始数据随游戏发布。

世界书确定的事实：

- 鲸湾是沿海环带的港湾城市，别称“结界心脏”，不是一座孤立农场或整个大区。
- 城市背山面海，港湾呈半月形；地图补充标注福特山地、鲸海。
- 建筑混合中式榫卯木构、欧式承重石墙，住宅有阁楼。
- 中央市集呈放射状，包含食品、工艺、表演、公告等公共功能；每周小集市、每月故事之夜。
- 各族共居、保留文化差异；使用通用代币，基础生活保障免费。
- 世界内部温和、四季分明；四季遵循南半球，不能画成一片南极冰原。
- 跨大区需长途交通；鲸湾与守护者小屋相距遥远，不能放成相邻可步行地点。

当前住宅、院落、邻里摊位、米拉与阿岚均为游戏新增内容，不冒充世界书已记载的人物或具体街区。春日花树、灯笼、船帆等视觉意象与已有 MV 场景相呼应，不能据此编造额外世界规则。

## 这一轮的范围

先改善现有街区的角色、阁楼建筑、曲檐、石木细部、花树、集市摊位、港岸和远景。继续使用代码生成的原创像素资产与真实 3D 场景。像素纹理要有明确轮廓、成组阴影和材质结构，不能仅提高随机噪点密度。日常玩法暂时保留；原型的 14 日换季尚需重构为世界书的南半球外历与结界纪念历，不能当作正式世界设定。游戏并未因此达到《八方旅人》的成品美术或《星露谷物语》的内容体量。

## 未来的整部《南极结界》

已有地图是地理与交通索引，不能自动等同于可玩的城市、人物和事件。以鲸湾的街区为第一个内容单元，未来逐步加入港区、中央市集、室内空间，再经交通扩展到其他区域。

结构采用“世界地图 → 目的地 → 当前场景”，保留地图地点 ID（如 whalebay、market、qiming）与区域 ID 的稳定映射。当前街区只是鲸湾的一部分，不能把其行走坐标当作大陆的经纬度。

- 世界存档保留人物关系、任务、日历、交通与收藏。
- 每个区域单独保存本地状态、加载纹理/场景资源；场景退出时释放 GPU 和音频资源。
- 长途旅行按地图航线与换乘处理，不在手机中连续渲染全大陆。
- 角色故事、生产生活、交通贸易和探索共同形成长期目标；不靠增加重复日常来冒充内容体量。
- 公开区域、灰区、黑区和旧痕遵守世界书的通行规则；不擅自把公共庇护所改成对居民打怪刷材料的世界。

## 手机端验收基准

这些是逐步达成的工程目标，不是已经覆盖全部设备的保证：

- 手机默认以稳定 30 帧为目标；降低阴影与内部像素比，保留主体辨识度。
- 优先共享像素贴图、实例化静态结构、复用几何体；内容细节尽量来自资产，而非额外实时灯光。
- 菜单/后台停止世界绘制；切场景清理纹理、几何体、渲染目标和监听器。
- 每轮保留同视角截图、绘制次数和资源数量，以及触屏、设备降速与真机结果；浏览器降速模拟不能标成手机实测。
- 在缺少真机结果时，明确列出设备验证缺口。游戏对模型服务没有运行时依赖。
