# 潮汐来信 · 0.8.7

首个可玩的送信序章：航行、靠岸、潮汐石路、旧邮局、灯塔灯镜、送信与回信；三个可选拾遗。此后继续扩展地图、交互与叙事。

程序与玩法不依赖模型和外部服务。游戏使用 Canvas 2D 绘制实时场景，Web Audio 合成环境音和音乐，封面和主要建筑、树木、船只为 AI 生成插画。场景透明素材及实际提示词见 [资产记录](assets/README.md)。画面、音效和叙事仍会继续打磨。

## 0.8.7 调整
