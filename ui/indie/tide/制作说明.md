# 潮汐来信 · 0.8.10

首个可玩的送信序章：航行、靠岸、潮汐石路、旧邮局、灯塔灯镜、送信与回信，另有三个可选拾遗。

## 统一的代码美术

场景内全部物件由 `paint.js` 的 Canvas 2D 函数绘制。树木、灯塔、房屋、人物、船只、码头、地形和海面统一使用平面色块、柔和投影与低对比纸纹。保留旗帜、海浪、行走和灯光动画。

标题与入口共用 `assets/cover-code.webp`，由同一个 `renderTideCover()` 函数绘制并导出。工作区使用 `node scripts/build-tide-cover.cjs` 重建封面（需要本机 Playwright 和 Chrome）。0.8.7 的 AI 插画已移除，不再下载或显示。

程序与玩法不依赖模型和外部服务，环境音和音乐由 Web Audio 合成。美术来源见 [资产记录](assets/README.md)。

## 存档与操作

存档键为 `st-iphonie:tide:v1:<账户 scope>`，只保存在当前浏览器，未纳入手机备份或云同步。沿用原来的存档格式与任务状态，无需重新开始。

手机建议横屏，用摇杆或点击地面移动；电脑支持键盘与全屏。点击移动按当前潮水寻找通路，键盘或摇杆接管时取消路线。

## 验证

模型测试覆盖潮水通路、等潮、涨潮救援、搁浅恢复、靠岸上船、完整任务、导航和存档修复。浏览器验证包括封面、横竖屏画面、航行、地图、暂停、全屏、继续与退出、邮局对话、灯镜解谜和结局回信。

## 0.8.9 交互

建筑具有步行碰撞范围；点击邮局、灯塔、角色、拾遗或码头，导航至地面交互点后自动互动。海图标出当前目标。手柄输入通过共享的 `../gamepad.js` 读取浏览器标准映射，采用死区和按下沿检测，菜单方向可延迟重复；设备丢失时暂停。

## 0.8.10 操控提示

界面根据实际使用的手柄、键盘、鼠标或触屏切换。手柄时显示互动 A、海图 X、手册 Y 和菜单键标记，隐藏虚拟摇杆；键鼠或触屏操作后恢复相应提示。空闲手柄不会覆盖新输入方式。手柄断开时恢复上一次非手柄提示。
