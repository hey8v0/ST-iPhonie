# 小手机 · 本机 Firefox

## 使用

在更新过的小手机浏览器内点「连接本机 Firefox → 启动教程 → 复制安装命令」，将命令粘贴到手机的 Termux。独立试玩包可以直接运行下载的 `ST-iPhonie-Termux.sh`。首次使用会列出缺少的软件包并询问是否安装。按提示设置画面密码，然后在小手机内输入同一密码。

以后输入 `iphonie-browser` 即可。命令检查状态，服务就绪后会把终端交回来。可以在同一个终端继续按原来的方式启动酒馆。已经在前台运行酒馆且没有命令提示符时，可以在下次启动酒馆之前安装；已在使用旧版前台 browser.sh 的用户先在旧服务里按 Ctrl+C。浏览器只使用 6089 和 5929。

在本机酒馆里打开小手机，点「浏览器 → 连接本机 Firefox」。也可以用安卓系统浏览器打开 `http://127.0.0.1:6089/vnc.html?autoconnect=1&resize=scale`。用 Firefox 自己的地址栏输入网址，左侧 noVNC 抽屉可唤起触屏键盘。结束使用时输入 `iphonie-browser stop`。

## 出现问题时

独立试玩安装文件会询问是否同步已识别的旧版小手机连接界面。自定义或无法唯一识别的安装会保留原样。需要还原试玩界面时可运行 `iphonie-browser restore-ui`，刷新酒馆即可。

- 「运行环境异常」且提到 ICU 或 XPCOM 时，启动命令会询问是否修复。也可以输入 `iphonie-browser repair`，确认后单独重装 Firefox 和 libicu。
- 「服务未启动」时运行启动命令，再点「重新连接」。安卓系统回收后台进程后同样适用。
- 「未检测到本机服务」表示当前网页无法取得本机服务状态。第一次连接时，浏览器无法区分尚未安装、已停止、访问被系统拦截。需要从同一台安卓设备的 localhost 或 127.0.0.1 打开酒馆。
- `iphonie-browser diagnose` 显示诊断摘要和私有日志位置。`iphonie-browser export` 生成可分享的 JSON，有下载目录权限时会另存到下载目录。小手机连接面板也能单独导出前端连接阶段。
- 完整输出位于 Termux 私有目录 `~/.local/share/st-iphonie-browser`，包括 install.log、daemon.log 和按大小轮换的 runtime.log。分享问题时请选择导出的 JSON。原始日志可能含路径、网址或其他私人内容。

## 启动与恢复

安装器按内容版本保存启动程序。已有 Firefox Profile、画面密码和登录数据保存在原来的目录。同一安装命令可以重复运行，运行中的会话可继续使用；更新的运行程序在下次停止再启动后生效。

服务依次检查文件、字体、Firefox 动态加载、X 显示可查询、Firefox 可见窗口，以及经过本机 WebSocket 桥的 RFB 协议头。终端就绪后，客户端仍需完成 VNC 身份验证，界面才显示已连接。Xvnc 或 Firefox 退出后最多恢复一次，重试使用仅作用于图形子进程的软件渲染设置。进程管理器若被安卓一并终止，需再次运行启动命令。

着色器扩展、GBM、DRI3 或字体路径警告可与成功启动并存。应结合后续窗口及握手检查判断影响。依赖加载失败会直接进入修复流程。通道退出消息需要结合哪个进程先退出分析。音频由本机 PulseAudio 提供。

本机服务监听回环地址，VNC 使用原有密码。网站页面无法提交普通命令；停止操作只允许持有本机私有令牌的客户端。浏览器不会要求 Termux 开启外部应用执行命令权限。



兼容测试版 2：取消未认证的 RFB 健康探测（包括每 30 秒的探测），保留 VNC 密码和黑名单保护。启动状态只说明本地进程、窗口和端口就绪，实际认证和首帧仍由客户端判断。更新时同意仅重启小手机浏览器服务，保留 profile。
